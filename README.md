# RoughBrush

Provides secure, end-to-end encryption for sensitive data transmission between devices using the Tor network protocol.

RoughBrush is built to be simple and practical, focusing on doing one thing well.

**Why RoughBrush?**

- Provides secure, end-to-end encryption for
- sensitive data transmission between devices
- using the Tor network protocol

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughBrush.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure RoughBrush, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
